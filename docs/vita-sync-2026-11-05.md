## Vita-specific behavior

The Vita button-combination change in `platform_vita.c` is not compiled for
Android or Switch. The dialog fix that ignores Vita rear-touch L2/R2 contacts is
now explicitly guarded with `__vita__`; other platforms retain their prior
controller release behavior. This merge adds no Vita renderer, rear-touch
mapping, Vita memory limit or nx.js dependency to those builds. Switch continues
to use EGL/OpenGL ES through Mesa/nouveau and its GPU.

Our Online/Offline/Debug profile boundaries, account/import restrictions, tuned
touch controls, startup feedback, APK identity/icon and signing safeguards are
retained. The native HTTP denial initially produced a premature "unhandled"
diagnostic before its caller attached a catch. The bridge now rejects that
synchronous capability failure asynchronously; it still cannot access accounts
from local modes or display an Online retry dialog for a blocked request.
