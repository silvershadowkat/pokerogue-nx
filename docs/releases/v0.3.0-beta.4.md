# PokeRogue NX 0.3.0-beta.4

An upstream-update beta for Nintendo Switch homebrew and Android. This release
uses krappaU's Vita runtime 1.1.6 and pins Debug to official PokeRogue 1.12.2.8.
Portrait mode and minigames are planned separately and are not included here.

## Changes

- Upstream memory cleanup for Pokemon sprites, animations, decoded audio and images.
- Starter-screen listener cleanup and a fix for late sprite loads replacing the selected Pokemon.
- Checksummed downloaded/compiled caches, safer config writes and save-backup recovery.
- Shared stock archives and isolated Online, Offline and SilverShadow Debug modes.
- Debug includes cheats, full Pokemon/move editors, saved builds and seeded custom runs.
- Retained the tuned native controller, contextual buttons and direct menu taps.
- Debug navigation remembers its place; restart-only options are disabled during runs.

## Downloads and installation

Android: install the APK. Existing beta.3 installs using the same signing key can
update in place. Older RC7 installs use the previous key: export local saves
before uninstalling if Android refuses the upgrade. Do not clear app data to update.

Switch: put pokerogue-nx.nro in sdmc:/switch/pokerogue-nx/. Use full application
homebrew mode (hold R while launching a game), not Album/applet mode. Keep existing
config and profile files. The NRO is provided directly; no outer ZIP is required.

The client bundles no game archive. Initial setup needs Wi-Fi. Online loads the
live official game and uses official account/cloud saves. Offline downloads the
stock game on request. Debug downloads a small compatible overlay plus its exact
stock base. Saves, cookies and settings are separated by mode; Debug cannot use
account APIs, and Online does not import local files. Full archive downloads are
used for stock updates, with resume and checksum validation. There are no binary
deltas. Minigames, Google Drive integration and portrait layout are not included.

## Validation and limits

Desktop native smoke 43/43 and Phaser checks 32/32 passed with fresh and cached
bytecode. Native cross-mode isolation and Switch-semantics cache/save writer
fixtures passed. Debug type checking, 96 feature tests and Vite build passed.
A fresh local Debug game selected a team, completed a battle and reached wave 2
using normal inputs without healing cheats. Platform build receipts accompany
the release. These checks do not establish physical Switch performance or test
every Pokemon, ability or move; please report hardware issues with reviewed logs.
Never share cookies, authentication files or unredacted save/profile data.
